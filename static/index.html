Handle Missing Values

Rows/columns are treated based on their missing percentage threshold.

🧹 Missing Value Strategy

<5% missing: drop entire row or column (your choice)  ·  5%–30%: replace with mean (numeric) or mode (categorical)  ·  >30%: drop entire column

Remove Duplicates

Detect and remove all fully duplicate rows from the dataset.

🔍 Duplicate Row Removal

Scans every row for exact duplicates across all columns and removes them, keeping only the first occurrence.

Remove Outliers

Uses the IQR (Interquartile Range) boxplot method to detect and remove outliers.

📦 IQR Outlier Removal

Points outside Q1 − 1.5×IQR or Q3 + 1.5×IQR are considered outliers and their rows are removed. Requires a numeric column.

Normalize Column

Apply Min-Max normalization to scale values between 0 and 1.

📐 Min-Max Normalization

Formula: (x − min) / (max − min)
All values in the selected column will be scaled to the [0, 1] range.
